## Reviewer Verification Requirements

Reviewers must confirm:

- deterministic replay semantics
- machine-checkable verification behavior
- bounded subsystem authority
- replay-safe equivalence guarantees
- immutable reconstruction consistency



## Explicit Non-Goals

The reviewer onboarding process does not introduce:

- AI governance
- exploit prediction
- trust scoring
- probabilistic inference
- adaptive verification
- autonomous enforcement
- semantic arbitration
